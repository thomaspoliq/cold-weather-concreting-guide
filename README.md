# Concreting in Cold Weather: A Small Jobs Guide

A plain language guide to placing concrete safely in winter: the minimum temperatures that matter, thawing and insulating the ground, using warm mixing water, protecting fresh work with blankets, and why curing takes longer in the cold.

## Deploying this page

The finished page is `index.html`, a single self-contained file with no external assets. It can be deployed as a static site (GitHub Pages, Vercel or Netlify) or served through the included Streamlit app (`app.py`, needs `streamlit` from `requirements.txt`).
